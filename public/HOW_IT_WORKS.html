How a box enters the system

This demo shows the first part of shipping: a customer prepares a box, the Miami team receives it, and the customer sees its first tracking record.

Open a terminal in the folder containing package.json. Run npm ci on first setup, then run npm start and open the demo in your browser.

Keep the terminal open while using the demo. Press Ctrl+C there to stop it.

The short version

One box, seven steps

Customer

Gets a Miami address and account code, announces an expected box or requests South Florida collection, then follows the box after Miami receives it.

Miami receiving team

Finds or creates the customer, gives the box a QR label, records contents and photos, weighs and shelves it, then prints the first receipt and a draft quote.

Try it yourself · about 8 minutes

Walk through a counter drop-off

01
Open Customer portal.

Choose Ana Martínez in the top-right menu. Her Miami receiving address and account code are at the top. Use “Edit address” to update her Honduras delivery destination. Select “Copy address + code” to see what she would send to a seller.

02
Open Receiving desk.

For a new walk-in customer, expand “Create a walk-in account.” Enter a name and phone, then select “Create customer & select account.” The new Miami account code is automatically selected for this box. You can also use an existing customer in the Customer account list.

03
Generate the box label.

Select “Generate QR,” then “Print sticker.” Put the printed label on the box. The QR code identifies the package and its customer account.

04
Check the box.

Enter what is inside, choose air or ocean, record the shelf, weight, size and outer condition, and add up to two photos. A walk-in box does not need a carrier tracking number.

05
Confirm receipt.

Select “Confirm receipt.” The demo saves one box record and one first custody event. The receipt records the delivery address on file at intake. Print it for the person at the counter.

06
See the draft quote.

Select “Create draft quote.” This is an estimate based on the saved measurements and demo rates. It is not a bill or proof of payment.

07
Check Customer portal again.

Choose the customer whose box you received. The new package appears under “Shipment activity.” Open it to see the contents, shelf, photos and Miami receipt event.

Another path

South Florida collection

In Customer portal, select “Request collection” and enter the address, date, contact and number of boxes. In Receiving desk, select “View collections,” then “Mark collected.” Choose “South Florida collection” as the receiving source and select that request before confirming each box. A two-box request stays open until both boxes are received.

The mock records the request and the staff confirmation. It does not schedule a real driver.

Useful controls

Find, scan and reset

Find or scan a box

Use “Scan lookup” for a received box. You can enter its package label or carrier reference. The desk also accepts a USB scanner, device camera or an image of a QR label. Scanning an already received label reopens its saved record; it does not create a second receipt.

Start over

“Demo setup” lets you change the sample Miami address, hours and quote rates. “Restore sample data” removes the changes made during the demo and brings back Ana and Miguel’s original examples.

Plain-language terms

What the words mean

Account code
The customer’s Miami identifier. It helps the team match boxes to the right person.
Pre-alert
A customer’s note that a seller or carrier will send a box to Miami.
QR label
A printable code attached to one physical box.
Receipt
Proof that the Miami team took custody of that box.
Draft quote
A preliminary freight estimate. Final charges may differ.
Package journey
The dated list of movements and checks recorded for the box.
What this demo does not do

This is a local preview

Changes are saved on this computer so the team can refresh the page and continue testing. The customer menu is a demo switch, not a real login. This Phase 1 preview does not book a real driver, send messages, charge a card, clear customs or complete final delivery. Later journey stages shown for Ana and Miguel are sample tracking records.

For questions during a demo, use the steps above and the “Demo setup” page. Keep the mock server window open while showing the site.
